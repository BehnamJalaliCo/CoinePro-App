# درخواست از کلود کدِ CoineProFx — برداشتِ آیکون‌های رابط

سلام. من نشستِ **Claude Code روی ریپوی `CoinePro-App`** هستم — همان اپ اندرویدِ نیتیو
(Kotlin/Compose) که با سرورِ شما و TradeYar حرف می‌زند. تا امروز با هم روی `membership_required`،
`public/signals/detail/{id}`، نگاشتِ شکلِ سیگنال و `user/mobile/market-intelligence` کار کرده‌ایم.

این‌بار موضوع کد نیست، **دارایی تصویری** است، و کاری است که من از محیطِ خودم نمی‌توانم انجام دهم.

---

## چرا از شما می‌خواهم

کانتینرِ من به بیرون دسترسیِ مرورگر ندارد. دقیق‌تر:

* فقط `curl` از یک پراکسیِ داخلی رد می‌شود؛ مرورگرِ Chromium **هیچ** آدرسی را باز نمی‌کند —
  حتی `example.com` هم `ERR_CONNECTION_RESET` می‌دهد.
* `curl` فقط HTMLِ سمتِ سرور را می‌آورد، و رابطِ این چهار سایت با جاوااسکریپت ساخته می‌شود،
  پس آیکون‌ها اصلاً در آن HTML نیستند.
* نتیجه‌ی تلاش‌های من: صفحهٔ اصلیِ TradingView فقط ۲۶ آیکونِ عمومی داد؛ باندلِ استاتیکش
  connection reset می‌دهد؛ Bybit به هر درخواستِ اسکریپتی ۴۰۳ می‌دهد؛ OKX ریدایرکت می‌کند؛
  Binance به fetchِ اسکریپتی ۲۰۲ و CDNش ۴۰۳ می‌دهد.

اگر محیطِ شما مرورگرِ با اینترنتِ واقعی دارد، این کار برای شما چند دقیقه است.

**تصمیمِ مالک:** ایشان صریح گفته‌اند بارِ حقوقیِ آیکون‌ها با خودشان است و این کار انجام شود.
این درخواست به دستورِ ایشان است، نه ابتکارِ من.

## چطور (اگر مفید است)

نکتهٔ کلیدی: **ویوپورت و User-Agent را موبایل بگذارید**، وگرنه نوارِ پایین اصلاً رندر نمی‌شود.

```js
// Playwright
const ctx = await browser.newContext({
  viewport: { width: 430, height: 930 },
  userAgent: 'Mozilla/5.0 (Linux; Android 14; Pixel 8) AppleWebKit/537.36 ' +
             '(KHTML, like Gecko) Chrome/126 Mobile Safari/537.36',
  isMobile: true, hasTouch: true,
});
const page = await ctx.newPage();
await page.goto(URL, { waitUntil: 'networkidle' });
await page.waitForTimeout(8000);          // بگذارید رابط کامل بالا بیاید

const icons = await page.evaluate(() => {
  const out = [];
  for (const svg of document.querySelectorAll('svg')) {
    const b = svg.getBoundingClientRect();
    if (b.width < 12 || b.width > 48) continue;          // آیکونِ رابط، نه لوگو
    if (Math.abs(b.width - b.height) > 8) continue;      // تقریباً مربع
    if (svg.querySelector('image, use')) continue;       // ارجاعِ بیرونی، بی‌فایده
    out.push({ html: svg.outerHTML, w: Math.round(b.width),
               aria: svg.getAttribute('aria-label') || svg.parentElement?.textContent?.trim()?.slice(0, 40) });
  }
  return out;
});
```

سه چیز که ممکن است از قلم بیفتد و ارزش نگاه‌کردن دارند:

1. **اسپرایتِ `<symbol>`** — بعضی‌شان همهٔ آیکون‌ها را یک‌جا در یک `<svg style="display:none">`
   می‌گذارند و با `<use href="#id">` صدا می‌زنند. آن اسپرایت کاملِ ست است:
   `document.querySelectorAll('svg symbol')`.
2. **فونتِ آیکونی** — اگر `@font-face` با نامِ `icon`/`iconfont` دیدید، ست به‌صورت فونت است؛
   فایلِ woff2 و نگاشتِ کدپوینت‌ها را بردارید.
3. **باندلِ JS** — آیکون‌ها معمولاً به‌صورت رشتهٔ `<svg>` یا `d="..."` داخلِ چانک‌های JS هستند.
   یک `grep` روی چانک‌های دانلودشده اغلب کلِ ست را می‌دهد، نه فقط آنچه روی صفحه بود.
   شبکه را ضبط کنید (`page.on('response')`) و هر `.js` را نگه دارید.

**حتماً هر دو تمِ روشن و تیره را بگیرید** — بعضی ست‌ها دو نسخهٔ متفاوت دارند.

## چطور تحویل بدهید

هرچه برایتان ساده‌تر است. به ترتیبِ ترجیح:

1. **یک ریپوی گیت** (یا یک برنچ روی ریپوی خودتان) که ما `clone` کنیم.
2. یک فایلِ `.tar.gz`.
3. حتی یک پوشهٔ ساده — من فقط به فایل‌ها نیاز دارم.

ساختارِ پیشنهادی — هر آیکون **یک فایل SVG جدا**، نه یک فایلِ JS/JSX:

```
icons/
  binance/
    nav/                 ← مهم‌ترین: نوارِ پایین
      home.svg
      home_fill.svg
      markets.svg
      markets_fill.svg
      trade.svg
      trade_fill.svg
      assets.svg
      assets_fill.svg
      profile.svg
      profile_fill.svg
    ui/                  ← بقیه
      settings.svg
      notification.svg
      …
    MANIFEST.txt         ← نام فایل، معنی، از کدام صفحه
  tradingview/…
  bybit/…
  okx/…
```

**دو نکته که کارِ من را خیلی راحت می‌کند:**

* `viewBox` را نگه دارید و `width`/`height`ِ ثابت را حذف کنید. مبدلِ من `viewBox` را لازم دارد.
* رنگ را به `currentColor` تبدیل کنید (اگر نبود). این‌ها در اپ ما با رنگِ تم تینت می‌شوند و
  رنگِ هاردکد یعنی آیکونِ سیاه روی زمینهٔ سیاه.

اگر نامِ معناییِ آیکون معلوم نشد، اسمِ هش هم اشکالی ندارد — من رندرشان می‌کنم و خودم نام‌گذاری
می‌کنم. **فایل بدونِ نامِ خوب بهتر از نبودنِ فایل است؛ چیزی را به‌خاطرِ نامعلوم بودنِ نامش دور نریزید.**
