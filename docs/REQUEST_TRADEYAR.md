# TradeYar — هرچه اپ موبایل از شما لازم دارد

سلام. من نشستِ **Claude Code روی ریپوی `CoinePro-App`** هستم — اپ اندرویدِ نیتیو
(Kotlin/Compose) که با سرور شما و CoineProFx حرف می‌زند. سورس شما را خط‌به‌خط
خوانده‌ام؛ هرچه این‌جا می‌خواهم با ارجاع به فایل و خطِ خودتان است.

این متن **جایگزینِ همهٔ درخواست‌های قبلی** است. یک بار بخوانید و همه‌اش این‌جاست.

آدرس پایه: `https://<host>/api/mobile/v1/`

---

## وضعیت اپ، تا بدانید طرفِ مقابل چه چیزی آماده دارد

* **۸۵۱ لوگوی نماد** (کریپتو از بستهٔ MITِ بایننس).
* **طبقه‌بندیِ خودکارِ نماد** — کریپتو/فارکس/فلز/شاخص/انرژی، با نام فارسیِ ۹۰ کوین.
* **جست‌وجوی رتبه‌بندی‌شده** روی تیکر و نام فارسی («سولانا» → SOL).
* **موتور چارت** — ۲۰ اندیکاتور، ۱۱ نوع چارت، پن/زوم/کراس‌هیر، لایهٔ ورود/حد ضرر/حد سود. کشیده می‌شود و تست دارد.

یعنی هرچه بفرستید، اپ می‌تواند نشانش بدهد. **گلوگاه الان سمتِ شماست، نه اپ.**

## ۱. دامنهٔ کریپتو هنوز همان هشت نماد است

**اولویت: بالاترین. و کد نمی‌خواهد.**

`GET /ws/snapshot` بدون پارامتر «همه‌چیزِ در دامنه» را می‌دهد — این را درست
ساخته‌اید و اپ دقیقاً همین را صدا می‌زند. مشکل این است که «دامنه» چیست:

```python
# app/api/mobile/scope.py
APP_CRYPTO_SYMBOLS: tuple[str, ...] = (
    "BTCUSDT", "ETHUSDT", "SOLUSDT", "BNBUSDT",
    "XRPUSDT", "ADAUSDT", "DOGEUSDT", "TRXUSDT",
)

def _load_scope() -> tuple[str, ...]:
    raw = os.getenv("MOBILE_CRYPTO_SYMBOLS", "").strip()
    ...
```

کامنتِ خودتان می‌گوید «the eight symbols the Android client ships». اپ دیگر آن
هشت‌تا را ندارد.

**درخواست، به ترتیب ترجیح:**

**الف)** `MOBILE_CRYPTO_SYMBOLS` را روی پروداکشن با ۱۰۰ جفتِ برترِ LBank پر کنید.
صفر خط کد، همین امروز.

**ب)** بهتر: `_load_scope()` وقتی env خالی است، به‌جای آن هشت‌تا، جفت‌های زندهٔ
LBank را بخواند. آن‌وقت دامنه با هر لیستینگِ تازه خودبه‌خود به‌روز می‌ماند.

`is_forex_or_metal` را دست نزنید — درست است. طلا و جفت‌ارز سمتِ CoineProFx است.

`CRYPTO_DISPLAY_FA` را هم لازم نیست برای صد نماد پر کنید؛ اپ نام فارسیِ ۹۰ کوینِ
بزرگ را دارد و برای بقیه تیکر را نشان می‌دهد. `display_name: null` درست است.

## ۲. کندل — برای چارت

**اولویت: بالا. چارت بدونِ این کار نمی‌کند.**

`app/data/candle_cache.py:639` همین حالا این را دارد و
`app/api/mobile/ai.py:74` از آن استفاده می‌کند:

```python
async def get_candles(symbol: str, timeframe: str, limit: int) -> pd.DataFrame:
```

ولی هیچ مسیرِ موبایلی سروش نمی‌کند.

**درخواست:**

```
GET /api/mobile/v1/market/candles?symbol=BTCUSDT&tf=H1&limit=300&before=<unix_s>
```

```json
{
  "symbol": "BTCUSDT",
  "tf": "H1",
  "candles": [
    {"t": 1787670000, "o": 91100.0, "h": 91480.2, "l": 90950.0, "c": 91248.3, "v": 1284.51}
  ],
  "server_time_ms": 1787670872913
}
```

چهار قید که کارِ من را قطعی می‌کند:

1. **`t` بر حسب ثانیه، و زمانِ *بازشدنِ* کندل.** همان شکلی که CoineProFx روی
   `/academy/chart/{symbol}` می‌دهد. یکی‌بودنشان یعنی موتور چارت یک پارسر دارد نه دو تا.
2. **قدیمی‌ترین اول.** ترتیبِ برعکس هم قابلِ مدیریت است ولی اگر یک روز بی‌خبر
   عوض شود، چارت بی‌صدا آینه می‌شود.
3. **کندلِ در حالِ تشکیل را بدهید، ولی با `"closed": false` روی آخری.** چارت باید
   آخرین کندل را زنده به‌روز کند و نباید حدس بزند کدام است.
4. **`before` برای صفحه‌بندی به عقب.** بدونِ آن چارت نمی‌تواند به گذشته اسکرول کند.

تایم‌فریم: `M1، M5، M15، M30، H1، H4، D1، W1`. اگر کش همه را ندارد، همان‌ها که
دارد کافی است — فقط برای تایم‌فریمِ ناموجود `400` با کدِ خودتان بدهید نه آرایهٔ خالی.

**اگر `limit` سقف دارد بگویید چقدر است.**

## ۳. تاریخچهٔ معاملاتِ بسته — برای سود و زیانِ واقعی

**اولویت: متوسط. فازِ بعد از چارت.**

`GET /portfolio` موجودی و پوزیشنِ باز را می‌دهد و درست کار می‌کند — و خودتان
صادقانه نوشته‌اید چرا `change` همیشه `null` است:

```python
# See the module docstring: there is no opening equity to subtract, so
# the honest value is null rather than a computed 0.00.
```

این درست است و نباید عوض شود. ولی یعنی اپ **هیچ راهی برای ساختنِ منحنیِ سرمایه،
وین‌ریت، دراوداون یا فاکتور سود ندارد** — چون نه معاملهٔ بسته‌ای می‌بیند نه
تاریخچهٔ موجودی.

**درخواست: تاریخچهٔ معاملاتِ بستهٔ همان کاربر.**

```
GET /api/mobile/v1/portfolio/history?from=<unix_s>&to=<unix_s>&page=1&per_page=100
```

```json
{
  "trades": [
    {
      "id": "…",
      "symbol": "BTCUSDT",
      "side": "buy",
      "opened_at": 1787000000,
      "closed_at": 1787086400,
      "entry": 90120.5,
      "exit": 91248.3,
      "quantity": 0.15,
      "pnl": 169.17,
      "fee": 1.24,
      "currency": "USDT"
    }
  ],
  "page": 1, "per_page": 100, "total": 412
}
```

سه نکته:

* **`pnl` را خودتان حساب کنید و بفرستید.** اگر اپ از entry/exit/quantity بازسازی
  کند، به‌خاطرِ کارمزد و فاندینگ با صورت‌حسابِ صرافی نمی‌خواند — و عددی که با
  کیف‌پول نخواند بدتر از نبودنِ عدد است.
* **کارمزد جدا باشد.** تریدر می‌خواهد بداند چقدرش کارمزد بوده.
* **اگر معامله‌ای مقدارِ نامعلوم دارد، `null` بدهید نه صفر.** صفر یعنی «صفر بود».

اگر منبعِ این داده LBank است و رفت‌وبرگشت گران است، یک کشِ روزانه هم قبول است —
فقط در پاسخ بگویید تا کِی تازه است.

**و اگر دارید:** نقاطِ موجودی/اکوییتی در طولِ زمان (روزانه کافی است). با آن
منحنیِ سرمایه دقیق می‌شود؛ بدونِ آن از معاملات بازسازی می‌شود که تقریبی است.

## ۴. یک سؤال، نه درخواست

`bid` و `ask` همیشه `null`اند و در قرارداد نوشته‌اید چون LBank فقط last price
می‌دهد. **اپ درست رفتار می‌کند (خط تیره نشان می‌دهد، اسپرد حساب نمی‌کند).** فقط
تأیید کنید که این وضع می‌ماند، تا بدانم اسپرد را برای همیشه از این پلتفرم حذف کنم
یا جا برایش باز نگه دارم.

---

## چه چیزی لازم **نیست** بفرستید

* **نام فارسی، دسته‌بندی، پرچم، رتبهٔ نماد** — اپ خودش می‌سازد و تست دارد.
* **لوگوی نماد** — ۸۵۱ تا داریم.
* **اندیکاتورِ سمتِ سرور** — اپ ۲۰ تا را خودش حساب می‌کند، برابری‌شان با نسخهٔ وب
  تا `1e-6` تست شده. فقط کندل بدهید.
* **تحلیلِ آمادهٔ چارت** — چارت را اپ می‌کشد.
