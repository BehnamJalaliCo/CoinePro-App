## کوتاهش

هیچ‌کدام از دو فید ما **درصد تغییر ۲۴ ساعته** نمی‌فرستند. نه تیکر، نه اسنپ‌شات.
`MarketQuote.changePercent` روی هر کوتی که تا امروز آمده `null` بوده — این را در کد
خودمان هم نوشته‌ایم و رفتار اپ بر همان بنا شده است.

نتیجه‌اش این است که شش قابلیت روی زمین مانده‌اند، و همه‌شان پشت **یک** درخواست‌اند.

## چه چیزی مسدود است

| قابلیت | چرا کار نمی‌کند |
|---|---|
| بیشترین رشد / بیشترین ریزش | بدون درصد تغییر، مرتب‌سازی معنا ندارد |
| مرتب‌سازی بر اساس حجم | حجم ۲۴ ساعته نداریم |
| نقشهٔ حرارتی | رنگ = عملکرد. بدون تغییر، همهٔ کاشی‌ها خاکستری‌اند |
| اسکرینر | امروز برای هر بازار **یک درخواست کندل** جدا می‌زند تا خودش تغییر را حساب کند |
| آمار صفحهٔ نماد | سقف و کف روز، حجم، گردش — هیچ‌کدام نیست |
| هشدار حجمی | مبنایی برای مقایسه وجود ندارد |

اسکرینر بدترینش است: الان برای پر کردن یک جدول، ده‌ها درخواست کندل به شما می‌زند.
این مسیر آن بار را از روی سرور شما هم برمی‌دارد.

---

## چه می‌خواهیم

```
GET api/mobile/v1/market/tickers
```

بدون پارامتر، کل کاتالوگ در یک پاسخ:

```json
{
  "tickers": [
    {
      "symbol": "BTCUSDT",
      "last": 77563.1,
      "change_percent_24h": -0.93,
      "high_24h": 78210.0,
      "low_24h": 77180.4,
      "volume_24h": 12844.51,
      "turnover_24h": 995123400.0,
      "funding_rate": 0.0001,
      "mark_price": 77561.8
    }
  ],
  "server_time_ms": 1756450000000,
  "cache_ttl_ms": 5000
}
```

**قواعدی که برای ما مهم‌اند** — همان‌هایی که در قرارداد عمق بازار هم توافق کردیم:

* عددی که ندارید **حذف شود**، نه اینکه `0` بگیرد. `volume_24h: 0` یعنی «هیچ معامله‌ای
  نشده»، که یک ادعاست؛ نبودنِ فیلد یعنی «نمی‌دانم»، که راست است.
* `cache_ttl_ms` را بفرستید تا بتوانیم صادقانه بگوییم این عدد چقدر کهنه است. همان
  کاری که `market/depth` می‌کند.
* اگر نمادی در پاسخ نبود، برای ما یعنی سرو نمی‌شود — نه اینکه صفر است.

## این داده را از کجا بگیرید

از همان صرافی‌ای که تیکر و کندل و دفتر سفارش را از آن می‌گیرید. **یک درخواست:**

```
اسپات:   GET /v2/ticker/24hr.do?symbol=all
فیوچرز:  GET /cfd/openApi/v1/pub/marketData?productGroup=SwapU
```

پاسخ فیوچرز دو چیز اضافه هم دارد که برای مخاطب ما — که عمدتاً روی فیوچرز است —
ارزش واقعی دارند و در همان بدنه‌اند:

* `prePositionFeeRate` → `funding_rate`
* `markedPrice` → `mark_price`

هر دو اختیاری‌اند. اگر ندهید، اپ آن‌ها را نشان نمی‌دهد و چیزی نمی‌شکند.

## چرا نرخ فاندینگ به‌تنهایی هم می‌ارزد

موتور هشدار ما پنج نوع تریگر دارد و همه‌شان روی قیمت‌اند. نرخ فاندینگ ششمی است که
با همان موتور، بدون کار تازه، کار می‌کند: «وقتی فاندینگ از فلان بالاتر رفت خبرم کن.»
برای کسی که پوزیشن باز نگه می‌دارد این هزینهٔ واقعیِ نگه‌داشتن است، و هیچ‌جای اپ
امروز نمی‌گویدش.

---

## آنچه از شما نمی‌خواهیم

**مارکت‌کپ.** می‌دانیم که صرافی عرضهٔ در گردش را منتشر نمی‌کند و شما هم منبع دیگری
ندارید. پس نه می‌خواهیم و نه در اپ جایی برایش باز می‌گذاریم — گزینه‌ای که هیچ‌وقت
داده نمی‌گیرد از نبودنش بدتر است.

**دادهٔ آن‌چین.** جداست و منبعش را نداریم. اگر روزی خواستیم، جداگانه حرف می‌زنیم.

## دو سؤال باز

۱. **سقف تاریخچهٔ کندل روی `market/candles` چقدر است؟** چند سال عقب می‌شود رفت؟ این
   دقیقاً همان چیزی است که تریدینگ‌ویو پشت پی‌وال گذاشته و ما می‌خواهیم رایگان بدهیم،
   ولی باید بدانیم چقدر داریم.

۲. **Open Interest** جایی در مستندات لبانک هست؟ در مستندات عمومی پیدایش نکردیم و شما
   دسترسی کامل‌تری دارید.
