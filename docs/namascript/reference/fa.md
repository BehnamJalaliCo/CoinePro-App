## سری‌های آماده

| فراخوانی | چه می‌دهد | خروجی |
| --- | --- | --- |
| `close` | قیمت بسته‌شدن هر کندل. | سری عددی |
| `open` | قیمت باز شدن هر کندل. | سری عددی |
| `high` | بالاترین قیمت هر کندل. | سری عددی |

| `ohlc4` | میانگین هر چهار قیمت کندل. | سری عددی |
