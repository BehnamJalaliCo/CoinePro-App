# TradeYar — دو چیز، برای بازارها و چارت

سورس را دوباره خط‌به‌خط خواندم. دو چیز مانده و **اولی حتی کد نمی‌خواهد** — یک
متغیر محیطی است.

آدرس پایه‌ای که اپ استفاده می‌کند: `https://<host>/api/mobile/v1/`

---

## ۱. دامنهٔ کریپتو هنوز همان هشت نماد است

`GET /ws/snapshot` بدون پارامتر «همه‌چیزِ در دامنه» را می‌دهد — این را درست
پیاده کرده‌اید و اپ الان دقیقاً همین را صدا می‌زند. مشکل این است که «دامنه»
چیست:

```python
# app/api/mobile/scope.py
APP_CRYPTO_SYMBOLS: tuple[str, ...] = (
    "BTCUSDT", "ETHUSDT", "SOLUSDT", "BNBUSDT",
    "XRPUSDT", "ADAUSDT", "DOGEUSDT", "TRXUSDT",
)

def _load_scope() -> tuple[str, ...]:
    raw = os.getenv("MOBILE_CRYPTO_SYMBOLS", "").strip()
    ...
```

یعنی اگر `MOBILE_CRYPTO_SYMBOLS` روی پروداکشن ست نشده باشد، دامنه همان هشت‌تایی
است که **اپ قدیم داشت** — و کامنتِ خودتان هم همین را می‌گوید: «the eight symbols
the Android client ships».

اپ دیگر آن هشت‌تا را ندارد. حالا می‌تواند هر تعداد نماد را طبقه‌بندی کند، مرتب
کند و جست‌وجو کند (فارسی و لاتین)، و **۸۵۱ لوگوی نماد** دارد که بیشترشان بی‌کار
نشسته‌اند.

**درخواست، به ترتیب ترجیح:**

**الف) `MOBILE_CRYPTO_SYMBOLS` را روی پروداکشن پر کنید.** صد جفت برترِ LBank
کافی است. صفر خط کد.

**ب) بهتر: دامنه را از خود LBank بسازید.** شما جایی جفت‌های زندهٔ صرافی را
دارید؛ اگر `_load_scope()` وقتی env خالی است به‌جای آن هشت‌تا از آن فهرست بخواند،
دامنه خودبه‌خود با لیستینگ‌های تازه به‌روز می‌ماند و دیگر کسی لازم نیست چیزی را
دستی نگه دارد.

فیلترِ `is_forex_or_metal` را دست نزنید — آن درست است و باید بماند. طلا و
جفت‌ارز سمت CoinePro-FX است، و همان‌جا هم می‌ماند.

**یک نکته اگر گزینهٔ (الف) را انتخاب کردید:** `CRYPTO_DISPLAY_FA` را لازم نیست
برای صد نماد پر کنید. اپ الان خودش نام فارسی ۹۰ کوینِ بزرگ را دارد و برای بقیه
تیکر را نشان می‌دهد. `display_name: null` کاملاً درست است.

## ۲. کندل — برای چارت لازم دارم و شما دارید

اپ دارد چارت نیتیو می‌سازد. برای فارکس دنبال کندل از CoinePro-FX هستم؛ برای
کریپتو از شما.

آنچه هست:

```python
# app/data/candle_cache.py
async def get_candles(symbol: str, timeframe: str, limit: int) -> pd.DataFrame:
```

که همین حالا کار می‌کند و `app/api/mobile/ai.py:74` از آن استفاده می‌کند — ولی
داخلی است و هیچ مسیر موبایلی آن را سرو نمی‌کند.

**درخواست: یک اندپوینت که همان را بدهد.**

```
GET /api/mobile/v1/market/candles?symbol=BTCUSDT&tf=H1&limit=300
```

```json
{
  "symbol": "BTCUSDT",
  "tf": "H1",
  "candles": [
    {"t": 1787670000, "o": 91100.0, "h": 91480.2, "l": 90950.0, "c": 91248.3, "v": 1284.51}
  ],
  "server_time_ms": 1787670872913
}
```

سه نکته که کارِ من را قطعی می‌کند:

* **`t` بر حسب ثانیه** (نه میلی‌ثانیه) و **زمانِ بازشدنِ کندل**. این همان شکلی
  است که CoinePro-FX روی `/academy/chart/{symbol}` می‌دهد، و یکی‌بودنِ این دو
  یعنی موتور چارت یک پارسر دارد نه دو تا.
* **قدیمی‌ترین اول.** ترتیب برعکس هم قابل مدیریت است ولی بی‌صدا اشتباه رندر
  می‌شود اگر یک روز عوض شود.
* **کندلِ در حالِ تشکیل را هم بدهید**، ولی اگر می‌شود با یک فلگ
  (`"closed": false` روی آخری). چارت باید آخرین کندل را زنده به‌روز کند و
  نمی‌خواهم حدس بزنم کدام‌یک است.

تایم‌فریم‌ها: `M1، M5، M15، M30، H1، H4، D1، W1` کافی است. اگر کش همه را ندارد،
همان‌هایی را که دارد بدهید و در پاسخِ یک اندپوینتِ ساده بگویید کدام‌ها موجودند —
یا اگر ساده‌تر است، `400` با کدِ خودتان برای تایم‌فریمِ ناموجود.

**اگر `limit` سقف دارد بگویید چقدر است.** اپ برای پن‌کردن به عقب باید صفحه‌بندی
کند و برای این کار یک `before=<unix_seconds>` هم لازم دارد (مثل `/academy/chart`
سمت فارکس). اگر بدون آن بدهید هم کار می‌کند، فقط چارت نمی‌تواند به گذشته اسکرول
کند.

---

## چیزی که لازم **نیست**

* **نام فارسی، دسته‌بندی، پرچم یا رتبهٔ نمادها.** اپ خودش می‌سازد و تست دارد.
* **لوگوی نماد.** ۸۵۱ تا داریم.
* **اندیکاتور سمتِ سرور.** اپ خودش حساب می‌کند؛ فقط کندل بدهید.

---

خلاصه: **اگر فقط یک کار بکنید، `MOBILE_CRYPTO_SYMBOLS` را پر کنید.** آن یک خطِ
تنظیمات، اپ را از هشت بازار به کلِ لیستِ شما می‌رساند و امروز قابلِ انجام است.
کندل کارِ بعدی است و به چارت گره خورده.
