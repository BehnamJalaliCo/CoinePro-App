# CoinePro-FX — دو چیز که اپ اندروید لازم دارد

این متن مستقل است. هیچ سند دیگری لازم نیست خوانده شود.

اپ اندروید CoinePro دو بک‌اند جدا دارد: CoinePro-FX برای فارکس (XAUUSD / XAGUSD) و
TradeYar برای کریپتو. این درخواست فقط دربارهٔ CoinePro-FX است.

آدرس پایه‌ای که اپ استفاده می‌کند: `https://coineprofx.com/api/`
همهٔ مسیرهای زیر نسبت به همین آدرس‌اند، یعنی `user/market-intelligence` می‌شود
`https://coineprofx.com/api/user/market-intelligence`.

## ۱. اندپوینت اخبار و تقویم بازار

شما خودتان پرسیدید «اندپوینت اخبار بازار برای اپ اصلاً نداریم — بسازیم یا از اپ
برداشته شود؟» پاسخ: **بسازید.**

اپ همین حالا این را صدا می‌زند و ۴۰۴ می‌گیرد:

```
GET user/market-intelligence
Authorization: Bearer <access_token>
```

پارسر اپ نوشته شده و منتظر است. شکل دقیقی که می‌خواند:

```json
{
  "server_time": "2026-08-25T09:14:00Z",
  "news": [
    {
      "id": "fx-2026-08-25-001",
      "title": "تصمیم نرخ بهرهٔ فدرال رزرو",
      "summary": "نرخ بدون تغییر ماند؛ لحن بیانیه تندتر از انتظار بود.",
      "source": "Reuters",
      "url": "https://www.reuters.com/…",
      "published_at": "2026-08-25T18:00:00Z",
      "sentiment": "bearish",
      "impact": "high",
      "relevance": ["gold"],
      "stale": false
    }
  ],
  "calendar": [
    {
      "id": "fx-cal-2026-08-26-cpi",
      "title": "شاخص قیمت مصرف‌کننده آمریکا",
      "country": "US",
      "currency": "USD",
      "scheduled_at": "2026-08-26T12:30:00Z",
      "impact": "high",
      "actual": null,
      "forecast": "0.3%",
      "previous": "0.2%",
      "relevance": ["gold", "silver"],
      "stale": false
    }
  ]
}
```

نکاتی که اپ روی آن‌ها حساب کرده — لطفاً دقیقاً همین‌ها:

- **همهٔ زمان‌ها ISO-8601 با `Z`** هستند، نه ثانیهٔ epoch. اپ آن‌ها را با
  `Instant.parse` می‌خواند و هر مقداری که پارس نشود، آن ردیف را کلاً می‌اندازد.
  (توجه: در `ai-signal` شما `generated_at` را ثانیهٔ عدد می‌فرستید و در
  `ai-vision` رشتهٔ ISO — اینجا لطفاً رشتهٔ ISO باشد تا سومین لهجه ساخته نشود.)
- **`sentiment`** یکی از `bullish` / `bearish` / `neutral` است. اپ `positive` و
  `negative` را هم می‌پذیرد. هر چیز دیگری «نامشخص» خوانده می‌شود و رنگی نمی‌گیرد.
- **`impact`** یکی از `low` / `medium` / `high` است. تقویم فقط وقتی به کاربر هشدار
  می‌دهد که `high` باشد.
- **`relevance`** آرایه‌ای از این‌هاست: `gold` (یا `xau` / `xauusd`)، `silver` (یا
  `xag` / `xagusd`). اپ از این برای هشدار «تا شش ساعت دیگر یک رویداد پرتأثیر روی
  طلا هست» استفاده می‌کند، پس خالی گذاشتنش یعنی آن هشدار هرگز نمایش داده نمی‌شود.
- **`stale`** را صریح بفرستید. اپ نبودِ این فیلد را «کهنه» فرض می‌کند، چون یک خبر
  بی‌تاریخ‌گذاریِ اعتبار از یک خبر زنده قابل تشخیص نیست و اشتباه در جهت امن بهتر است.
- **`url`** اگر باشد باید `https` باشد؛ اپ هر چیز دیگری را دور می‌ریزد.
- `id`، `title`، `source` و `published_at` اجباری‌اند؛ ردیفی که یکی‌شان را نداشته
  باشد نمایش داده نمی‌شود.
- اگر خبری نیست، `"news": []` بفرستید، نه ۴۰۴ و نه ۲۰۴.

### چند خبر و از کجا؟

- بین ۱۵ تا ۵۰ خبر اخیر کافی است. اپ خودش صفحه‌بندی نمی‌کند.
- منبع با شماست (Finnhub که همین حالا دارید، یا هر چیز دیگر). فقط عنوان و خلاصه را
  **فارسی** بدهید اگر می‌توانید — اپ متن سرور را عیناً نمایش می‌دهد و هرگز ترجمه
  نمی‌کند، پس اگر انگلیسی بفرستید کاربر فارسی‌زبان انگلیسی می‌بیند.
- تقویم اقتصادی هفتهٔ جاری و هفتهٔ بعد کافی است.

## ۲. فیلدهای اشتراک در `user/me`

اپ حالا یک کارت اشتراک روی صفحهٔ اصلی دارد که فقط برای کسی که اشتراک دارد نمایش
داده می‌شود. برای کسی که ندارد **هیچ چیز** نشان داده نمی‌شود — نه حالت خالی، نه
پیشنهاد خرید — و هیچ امکانی هم از او گرفته نمی‌شود. سیگنال‌ها، اجرای معامله و بقیه
برای هر حساب واردشده کاملاً باز است. تنها چیزی که یک امکان را می‌بندد، ردِ صریح
خود سرور به یک درخواست مشخص است.

اپ این فیلدها را از `user/me` می‌خواند و همه‌شان همین حالا وجود دارند:

| فیلد | چه‌کار می‌کند |
| --- | --- |
| `is_paid` | اگر true باشد کارت نمایش داده می‌شود |
| `is_vip` | اگر true باشد کارت نمایش داده می‌شود و نشان «عضو ویژه» می‌گیرد |
| `plan` | نام طرح، **عیناً** نمایش داده می‌شود — اپ آن را ترجمه نمی‌کند |
| `plan_expires_at` | رشتهٔ ISO-8601؛ تاریخ و «N روز باقی مانده» از آن می‌آید |

فقط دو درخواست:

1. **`plan` را به فارسی بدهید** اگر قرار است کاربر فارسی‌زبان ببیندش. الان `monthly`
   می‌آید و اپ همان را می‌نویسد، چون اپ حق ندارد اسمی را که خودش نگذاشته ترجمه کند.
2. **`plan_expires_at` رشتهٔ ISO با `Z` باشد.** اگر تاریخ شمسی می‌فرستید بگویید تا
   اپ جور دیگری بخواند؛ الان هر چیزی که ISO نباشد بی‌صدا نادیده گرفته می‌شود و
   کاربر تاریخ انقضایش را نمی‌بیند.

**مهم:** اپ هرگز خودش تصمیم نمی‌گیرد که اشتراکی تمام شده. اگر `plan_expires_at`
گذشته باشد ولی `is_paid` هنوز true باشد، اپ اشتراک را زنده می‌داند. تصمیم با سرور
است — ساعتِ یک روز جلوترِ گوشی نباید چیزی را که کاربر بابتش پول داده از او بگیرد.

## چیزی که لازم **نیست**

- صفحهٔ خرید اشتراک داخل اپ نمی‌خواهیم. مراحل خرید همان‌جایی می‌ماند که هست.
- اندپوینت جدا برای «آیا اشتراک دارم» نمی‌خواهیم؛ همان `user/me` کافی است.
