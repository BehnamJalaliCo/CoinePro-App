# CoinePro-FX — دو چیز، برای اینکه اپ بتواند بازارها و چارت را نشان بدهد

باز هم سورس را خط‌به‌خط خواندم، و این‌بار دو چیز پیدا شد که هر دو **در سرور شما
هست ولی اپ موبایل به آن نمی‌رسد**. هیچ‌کدام ساختن از صفر نیست.

آدرس پایه‌ای که اپ استفاده می‌کند: `https://coineprofx.com/api/`

---

## ۱. اپ نمی‌تواند بفهمد شما چه نمادهایی دارید

این مهم‌ترین چیزِ این متن است.

اپ تا امروز **هشت نماد** نشان می‌داد، چون هشت‌تا داخل کدِ خودش نوشته شده بود.
حالا اپ می‌تواند هر تعداد نماد را طبقه‌بندی، مرتب و جست‌وجو کند (فارسی و لاتین،
با رتبهٔ نقدشوندگی) — و ۸۵۱ لوگوی نماد هم دارد. تنها چیزی که کم است این است که
**نمی‌داند از شما چه چیزی بخواهد.**

آنچه در سورس هست:

```python
# src/api/routes/mobile/snapshot.py
DEFAULT_SYMBOLS = ("XAUUSD", "XAGUSD")
_MAX_SYMBOLS = 20

def _allowed() -> set[str]:
    return {s.upper() for s in settings.SYMBOLS}
```

یعنی:

* `GET /ws/snapshot` بدون پارامتر فقط طلا و نقره می‌دهد.
* هر نمادی خارج از `settings.SYMBOLS` با `unsupported_symbol` رد می‌شود — و
  چون خطا روی کلِ درخواست است، یک نمادِ اشتباه کلِ عکسِ لحظه‌ای را می‌خوراند.
* و **هیچ اندپوینتی وجود ندارد که `settings.SYMBOLS` را برگرداند.**

پس اپ در یک بن‌بست است: نمی‌تواند نماد بخواهد چون نمی‌داند چه چیزی مجاز است، و
نمی‌تواند بفهمد چه چیزی مجاز است چون کسی به او نمی‌گوید.

**درخواست: یک اندپوینت که فهرست نمادهای این پلتفرم را بدهد.**

```
GET /user/markets        (یا هر آدرسی که به ساختار شما می‌خورد)
```

```json
{
  "symbols": ["XAUUSD", "XAGUSD", "EURUSD", "GBPUSD", "USDJPY", "US30", "USOIL"],
  "server_time_ms": 1787670872913
}
```

آرایهٔ رشته‌ای کافی است. دسته‌بندی، نام فارسی، پرچم و ترتیبِ نمایش را اپ خودش
می‌سازد — این کار تمام شده و تست دارد. اگر خواستید بیشتر بدهید بدهید، ولی لازم
نیست.

**مقایسه‌ای که کمک می‌کند:** TradeYar همین حالا این را دارد. در قراردادشان نوشته
«`symbols` را حذف کنید تا همه‌چیزِ در دامنه را بگیرید» — و اپ دقیقاً همین کار را
می‌کند و کلِ جهانِ کریپتو را می‌شناسد. اگر `GET /ws/snapshot` بدون پارامتر روی
سرور شما هم به‌جای دو نماد **همهٔ** `settings.SYMBOLS` را بدهد، هیچ اندپوینت
تازه‌ای لازم نیست و کار همین‌جا تمام است. این ساده‌ترین راه است.

اگر این کار را می‌کنید، لطفاً `_MAX_SYMBOLS = 20` را هم برای حالتِ «بدون
پارامتر» بی‌اثر کنید، وگرنه پاسخ به بیست‌تا بریده می‌شود.

## ۲. کلِ بک‌اندِ چارتِ بازارنما روی سرور شماست و قفل است

این را با تعجب پیدا کردم. `src/api/routes/academy.py` این‌ها را سرو می‌کند:

| مسیر | چه می‌دهد |
| --- | --- |
| `GET /academy/chart/symbols` | همهٔ نمادهای MT5 از `bn:fxsyms` + همهٔ جفت‌های LBank |
| `GET /academy/chart/{symbol}` | کندل‌ها به شکلِ `{t,o,h,l,c,v}` + اندیکاتورهای سمتِ سرور |
| `GET /academy/chart/{symbol}/range` | بازهٔ دادهٔ موجود |
| `POST /academy/chart/analyze` | تحلیل AI با سطوح حمایت/مقاومت |
| `/academy/bn/*` | چیدمان‌ها، اسکریپت‌های نماساکریپت، واچ‌لیست، هشدار، سیگنال AI، خبر، تقویم |

این دقیقاً همان چیزی است که اپ برای چارت لازم دارد و ما فرض کرده بودیم باید از
صفر بسازیم.

مشکل فقط یک خط است:

```python
async def chart_symbols(st: AcademyStudent = Depends(current_student), ...):
```

`current_student` توکنِ `scope=academy` می‌خواهد که به `AcademyStudent` وصل باشد،
و اپ موبایل توکنِ `User` دارد. دو هویتِ جدا.

ولی خودتان مکانیزمش را دارید — `academy.py:103`، حالتِ `BN_STANDALONE_AUTH`، که
هویت را فقط از claimهای JWT می‌سازد و با **همان** `JWT_SECRET_KEY` امضا شده است.

**درخواست، هرکدام برایتان ساده‌تر است:**

الف) توکنِ موبایل روی این مسیرها هم پذیرفته شود؛ یا

ب) یک اندپوینت که برای کاربرِ واردشده یک توکنِ academy بسازد:

```
POST /user/academy-token
→ {"token": "...", "expires_at": "2026-08-26T12:00:00+00:00"}
```

گزینهٔ (ب) را ترجیح می‌دهم چون هیچ مسیر موجودی را دست نمی‌زند و اگر بعداً خواستید
دسترسی academy را محدود کنید، یک‌جا قابلِ کنترل است.

**اگر دلیلی هست که این مسیرها نباید برای کاربرِ موبایل باز شوند، همان را بگویید.**
یک «نه» با دلیلش برای من به‌اندازهٔ «بله» ارزش دارد، چون آن‌وقت چارت را از راهِ
دیگری می‌سازیم به‌جای اینکه منتظر بمانیم.

---

## چیزی که لازم **نیست**

* **کندل برای کریپتو از شما.** آن سمت TradeYar است و جدا پیگیری می‌شود.
* **دسته‌بندی، نام فارسی، پرچم یا رتبهٔ نمادها.** اپ خودش می‌سازد.
* **`sentiment` روی market-intelligence.** همان `null` بماند بهتر است؛ اپ
  `UNKNOWN` را درست نشان می‌دهد و یک سیگنالِ نیمه‌ساخته که خواننده رویش عمل کند
  از نبودش بدتر است.

---

خلاصهٔ عملی: **اگر فقط یک کار بکنید، بگذارید `GET /ws/snapshot` بدون پارامتر همهٔ
نمادها را بدهد.** آن یک تغییر، اپ را از هشت بازار به همهٔ بازارهای شما می‌رساند.
